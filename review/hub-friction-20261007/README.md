# Compact friction-only servo hub

The owner confirmed that the servo holder is smaller than the garden auger and requires friction retention only. The four internal tabs were accidental. The authorized revision removes them and uses the auger reference's smooth trial diameter 5.70 mm / depth 3.70 mm pilot, with its 0.15 mm entry chamfer. Straight cylindrical engagement is 3.55 mm. No separate horn, retaining screw or screw-access hole is used.

The existing diameter 12 mm hub flange is retained. Minimum radial wall at the chamfer mouth is 3.00 mm; the bore floor is world Z30.00 and the opposite axle socket floor remains Z34.00, leaving a 4.00 mm solid web. The flange servo face stays Z26.30. The four protruding tab tips at Z26.10 are removed. The outer journal and opposite axle socket remain unchanged.

[ISO and native OCCT section views](hub-friction-views.png). [Complete five-part PETG Bambu project](assembly-petg-friction-hub.3mf) contains both shells, both actual mirrored clips and the revised hub. Use this file rather than the earlier assembly-petg.3mf with tabs.

Native validation passes: 374 features, seven bodies, six unchanged meshes/topology signatures, unchanged assembly poses and unchanged non-hub contact records. The hub has no modeled assembly interference. The purchased servo reference omits its detailed spline shaft, so this does not validate the real hardware's exposed length or tight fit. Native STEP contains one manifold solid; fine STL is connected, closed, positively oriented and has two-incidence edges at 1e-5 mm welding. See review.json and mesh-audit.json.

Slicing passes in Bambu Studio 2.8.2.61 with X2D 0.4 mm nozzle / Bambu PETG Basic / 0.12 mm main layers / 0.20 mm first layer / Classic walls / four requested walls /25% gyroid. The hub is printed axle face down, servo socket up; only the hub enables build-plate tree supports. All five names, triangle counts and heights match the intended imported geometry. Native CLI exit and result codes are zero; no plate warning. Estimated total: 2.37 hours, 22.94 g. Native toolpath samples show no extrusion in the central servo-socket interior above its floor; supports remain in the hub region. These sample checks do not measure the printed bore. See native-slice.json, assembly-project.json and toolpath-audit.json. No print was sent.

Friction holding force, axial pull-off and torque capacity have not been established. Diameter 5.70 mm is the auger's trial dimension, not a calibrated fit result for this particular servo and printer. Check that the actual shaft seats and the hub does not split, rock or slip. Existing detent strain analysis is retained because the clip and housing solids are unchanged; no new detent analysis was needed.

Thirty obsolete operations (four tab sketch/extrude/move/join chains and the redundant dome construction) are removed; one native entry chamfer is added. The existing sketch/extrude/cut form the socket. Preserved body and occurrence IDs are not renumbered. The parent design is commit 66a71d0. The historical tangent-corner-flex reference is unchanged, and a new hub-friction-fit.json validation reference records this intentionally changed hub.

Reproduction scripts retain the local native replay/export and slicing procedure.
