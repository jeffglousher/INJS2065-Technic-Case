# Active CAD source

`current.model.json` contains the 392-feature native parametric construction. `current.nbcad` is the corresponding saved native CAD project. Both represent the same accepted geometry.

Shared sketches and planes replace duplicate definitions. Solid operations, body IDs, assembly poses and geometry are preserved. High-water ID counters remain intact to avoid collisions on future edits.
