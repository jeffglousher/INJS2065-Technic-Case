# Active CAD source

`current.model.json` contains the 403-feature native parametric construction, schema 14. `current.nbcad` contains the matching native project payload.

The current revision retains two rows of four blind hex pockets and four centered S-curve detents per clip. Tangent corner reliefs and R0.25 side-wall blends retain 0.8976 mm minimum in-plane wall and 1.00 mm backing. The nub crest is R0.80 with R0.40 tangent outer arcs; protrusion remains 0.20 mm. Hidden rounded receiver caps preserve the exterior housing hex mouths. Both clip bodies and both hidden housing seats change; servo, bearing and hub geometry remain unchanged.

The original R1.6 relief source was replaced with a correctly named tangent profile in the same construction position. The existing relief revolve, copies, mirrors and cuts remain shared. Two native fillet features bring the earlier 401-feature history to 403. Earlier design states remain in Git.
