# Active CAD source

`current.model.json` contains the 401-feature native parametric construction. `current.nbcad` is the matching saved native CAD project. Both contain the authorized local thinning at the four detent corners of each clip.

The earlier 392-feature deduplicated construction is retained. Nine native features add one shared rounded R1.6 relief, copies, a mirror and two cuts. Each relief opens into its existing hex pocket, narrows the corner wall to approximately 0.90 mm and leaves 1.00 mm minimum backing. Full walls, detent profiles, external clip outline, housing geometry and assembly poses are retained. High-water ID counters remain intact.
