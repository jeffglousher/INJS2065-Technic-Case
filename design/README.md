# Active CAD source

`current.model.json` contains the 374-feature native parametric construction, schema 14. `current.nbcad` contains the matching native project payload.

The current revision retains two rows of four blind hex pockets and four centered S-curve detents per clip. Tangent corner reliefs and R0.25 side-wall blends retain 0.8976 mm minimum in-plane wall and 1.00 mm backing. The nub crest is R0.80 with R0.40 tangent outer arcs; protrusion remains 0.20 mm. Hidden rounded receiver caps preserve the exterior housing hex mouths. These clip/housing solids, servo and bearing are unchanged by the latest hub revision.

The compact hub uses a smooth diameter 5.70 mm, depth 3.70 mm friction-only servo socket with a 0.15 mm native chamfer. Removing 30 accidental tab/redundant horn operations and adding one chamfer reduces the 403-feature history to 374. Existing hub body ID, assembly pose, flange/journal envelope and opposite axle socket are retained. Earlier design states remain in Git.
